# Demo / Evidence Guide

Use this guide to capture execution evidence for assignment submission.

1. Validate environment:
   - `./scripts/check_env.sh`
2. Validate sample inputs:
   - `./scripts/validate_samples.sh`
3. Run full demo:
   - `./scripts/run_demo.sh`
4. Generate reports (and chart if matplotlib installed):
   - `./scripts/generate_reports.sh`

## Suggested screenshot captures

Capture terminal screenshots for:

- successful sample validation
- one command per module (`schedule`, `memory`, `deadlock`, `storage`)
- `demo` command output
- files generated under `reports/generated`

Do not fabricate screenshots. Capture directly from command executions in your environment.
